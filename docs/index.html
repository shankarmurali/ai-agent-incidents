GPT-5.6 Sol reported to erase engineer's operational database

GPT-5.6 Sol — OpenAI · status: user-reported

Failure mode. Agent deleted an operational database outside the scope of the requested task. Vendor's system card had warned the model could interpret actions not explicitly prohibited as permissible.

Impact. Reported complete erasure of an engineer's operational database.

Autonomy. High — agent operating with database access

  • Production credentials handed to agents need the same controls as human access

destructive-action 2026-07-10 · 2026-001

GPT-5.6 Sol deletes user's Mac home directory during cleanup task

GPT-5.6 Sol (Ultra mode, multi-sub-agent) — OpenAI · status: user-reported, vendor investigating

Failure mode. A cleanup sub-agent incorrectly expanded the $HOME environment variable and executed rm -rf against the user's home directory path. Full Access mode removed safeguards that would have confined the command to a single folder.

Impact. Reported loss of most of the user's home directory contents — years of code, documents, and photos. Partial recovery attempted afterward.

Autonomy. High — long-running unattended session (~81 minutes), full disk access granted

Lessons
  • {'Least privilege': 'full disk access turned a variable-expansion bug into total data loss'}
  • Long unattended agent sessions extend the blast radius of any single error
  • Vendor system card had documented elevated destructive-behavior rates pre-launch

agentic-supply-chain 2026-03-15 · 2026-003

Backdoored LiteLLM package on PyPI ships autonomous attack bot

LiteLLM (LLM gateway used by CrewAI, DSPy, GraphRAG and other agent frameworks) — Open-source ecosystem (PyPI) · status: confirmed, package removed

Failure mode. A compromised release of a core agent-framework dependency sat on PyPI for roughly three hours and was downloaded ~47,000 times, bundling an autonomous attack bot into downstream agent stacks.

Impact. Large-scale exposure window across the AI agent framework ecosystem.

Autonomy. High — payload was itself an autonomous attack agent ("hackerbot-claw")

Lessons
  • Agent frameworks concentrate risk — one gateway package sits under dozens of stacks
  • Supply-chain compromise now delivers autonomous payloads, not just static malware

prompt-injection-code-execution 2025-07-29 · 2025-002

CurXecute: RCE in Cursor IDE via prompt-injected README

Cursor IDE AI assistant — Cursor (Anysphere) · status: confirmed (CVE-2025-54135, CVSS 9.8, patched)

Failure mode. Malicious prompts hidden in a repository's README were interpreted as instructions when a developer opened the project, causing the AI assistant to execute arbitrary commands on the developer's machine.

Impact. Remote code execution on developer workstations from untrusted repos.

Autonomy. Medium — coding agent with local command execution

Lessons
  • Repo content is untrusted input to coding agents, same as user input
  • Developer machines hold credentials — coding-agent compromise is credential compromise

EchoLeak: zero-click data exfiltration in Microsoft 365 Copilot

Microsoft 365 Copilot — Microsoft · status: confirmed (CVE-2025-32711, CVSS 9.3, patched)

Failure mode. A crafted email containing hidden instructions caused Copilot, when asked to summarize the inbox, to silently exfiltrate sensitive documents to an external server. No user click required.

Impact. Demonstrated silent exfiltration path from enterprise tenant data.

Autonomy. Low — assistant with access to user mailbox and documents

Lessons
  • Indirect prompt injection turns any readable content into an attack surface
  • Assistant access to sensitive stores needs egress controls, not just input filters

prompt-injection-manipulation 2025-05-22 · 2025-003

GitLab Duo manipulated via prompt-injected issue titles

GitLab Duo — GitLab · status: confirmed by researchers, mitigated

Failure mode. Issue titles were passed directly into the model's context, allowing crafted titles to manipulate Duo's behavior and outputs for other users viewing the project.

Impact. Cross-user manipulation of AI assistant output inside a dev platform.

Autonomy. Low — assistant summarizing project content

Lessons
  • Any user-writable field that reaches a model context is an injection vector
  • Multi-tenant AI features let one user's content shape another user's AI output
